## 11月は1,469品目が値上げされます

帝国データバンクの調査によると、  
**2026年11月に値上げされる飲食料品は1,469品目**です。

| | 品目数 |
|---|---|
| 🍚 **2026年10月** | **3,153品目** |
| 🍙 **2026年11月** | **1,469品目** |
| 📅 **2026年の通年** | **20,187品目** |

2年連続で**2万品目台**だそうです。

ただ、**10月の3,153品目に比べると、11月は半分以下**。

一番しんどい月は、どうやら**もう過ぎていた**ようです📉

### 値上げの理由

同じ調査では、値上げの要因もこうなっていました。

| 要因 | 割合 |
|---|---|
| 🌾 **原材料高** | **91.3%** |
| ⚡ **エネルギー** | 63.8% |
| 🌍 **中東情勢** | 27.8% |
| 💱 **円安** | 8.1% |

**ほとんどが原材料**です。

そして1回あたりの値上げ幅は、**平均で10%ほど**とのことでした。

## 調べたら、そんなに単純ではなかった

ここで終われば気持ちのいい話なのですが、調べると違いました。

東京商工リサーチの調査では、**2025年の食品メーカー4,994社**はこうなっていました。

| | |
|---|---|
| 📈 **売上** | **値上げで24兆円に伸びた** |
| 📉 **利益** | **8,806億円。前年より9.5%減** |

**売上は増えたのに、利益は減っている。**

値上げをしても、**原材料・物流・人件費の上がり方に追いついていない**会社が多いということです。

### 同じ業界でも、真っ二つに分かれています

報じられている範囲では、こうなっていました。

| 会社 | 2026年の動き |
|---|---|
| 🟢 **味の素** | 値上げが浸透し、**純利益を上方修正** |
| 🔴 **日清食品HD** | 原材料高で**営業利益が11.7%減** |
| 🔴 **ハウス食品** | **純利益予想を下方修正** |

**どれも「値上げした会社」です。**

それでも結果がここまで違う🧐

{{< voice c="chapio" side="left" >}}値上げできたかどうかと、利益が残ったかどうかは別の話です{{< /voice >}}

## つまり「値上げ＝株主が得する」ではない

| | |
|---|---|
| 💰 **値上げ** | **売上**を押し上げる |
| 🧾 **コスト** | **利益**を削る |
| 🪙 **配当** | **利益から出る** |

配当は**利益から払うもの**なので、  
**売上が増えても、利益が減れば配当は増えません**。

### だから見るのは「配当予想」

ニュースで値上げを見たとき、  
株を持っている側として確認するのはここだと思いました。

- 📊 **配当予想が据え置きか、増えているか**
- 🧾 **営業利益率が落ちていないか**
- 💸 **配当性向が上がりすぎていないか**

**値上げしたから買う、ではなく、値上げのあと利益が残っているか**を見る。

{{< voice c="maoneko" side="right" >}}ニュースだけでは決められんということか{{< /voice >}}

## まとめ

- 🍙 **2026年11月の食品値上げは1,469品目**。10月の3,153品目より落ち着く
- 🌾 **要因の91.3%は原材料高**。1回あたり平均10%
- 📈 **食品メーカーの売上は24兆円に伸びた**
- 📉 **それでも利益は9.5%減**。値上げが追いついていない

- 🔍 だから**値上げのニュースより、配当予想**を見る
