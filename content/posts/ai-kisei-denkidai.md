## たどっていくと、電気代の話だった

出口調査の数字を見て、なるほどと思いました。

| 有権者が気にしていたこと | 割合 |
|---|---|
| 💸 **生活費** | **約9割**が「投票先を決める重要な要素」 |
| 📈 **インフレで家計が苦しい** | **約8割** |
| 🫵 **物価の責任は大統領にある** | **62%** |
| 🛃 **関税が経済を傷つけた** | **約3分の2** |
| ⚡ **データセンターが電気料金を押し上げる** | **77%** |

一番下の行です。

**電気代が高いのはデータセンターのせいだ、と7割以上が考えていた。**

### データセンターは電気を大量に使う

![丘の上に並んで座り、夜景を見下ろしているしろとらとミュタの後ろ姿。街のあかりの中で、窓のない大きな四角い建物だけが明るく光っているイラスト](/images/posts/ai-kisei-denkidai-02-yakei.jpg#wide)

AIを動かすには、計算をするための巨大な施設が要ります。

それがデータセンター。

そして、ここが大量の電気と水を使います。

近所に建てば、その地域の電気代に影響する可能性がある。

**住んでいる人にとっては、AIの話ではなく生活費の話**になります。

## だから、規制の話が出てきた

選挙で勝った側は、こういうことをしようとしていると報じられています。

| | 何をしようとしているか |
|---|---|
| ⚡ **電気料金** | データセンターによる値上がりから**消費者を守る法案**を出す計画 |
| 💧 **電力と水** | 使用量の規制強化を公約に掲げた当選者がいる |
| 🏛️ **AIの検証** | 第三者による検証の義務化、製品の損害責任の明確化 |
| 🏘️ **地方** | 建設の禁止や制限が、住民投票で可決された自治体がある |

市場はこれを見て、こう考えたようです。

> **データセンターの建設が止まるなら、そこに入る半導体も売れなくなる。**

だから半導体株が売られた。
