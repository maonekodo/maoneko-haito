高配当株を選んでいるとき、最初に引っかかったのがこれでした。

**利回りが高い順に買ったら、なぜダメなのか。**

利回り5%の銘柄が10個あるなら、その10個を買えばいい気がします。

{{< voice c="maoneko" side="right" >}}上から順に買ったらダメなん？{{< /voice >}}

{{< voice c="chapio" side="left" >}}それ、同じ業種ばっかりになりますよ！{{< /voice >}}

ここで出てくるのが **セクター分散** でした。

---

## セクターというのは業種のこと

株は **業種（セクター）** で分類されています。

化学、小売、不動産、情報・通信、といった分け方です。

セクター分散は、**その業種をなるべく散らして持つ**という考え方になります。

---

## なぜ業種を散らすのか

それは、

**同じ業種の会社は、同じ理由で一緒に苦しくなるからです。**

| もし起きたら | 影響を受ける業種 |
|---|---|
| 原油が高くなる | 運輸・化学 |
| 金利が上がる | 不動産・銀行 |
| 人が外に出なくなる | 小売・外食 |

高配当株で一番困るのは **減配**（配当が減ること）。

同じ業種ばかり持っていると、**その業種に逆風が吹いた瞬間に、  

持っている銘柄がまとめて減配する**ことに。

{{< voice c="maoneko" side="right" >}}確かに全部来たら逃げ場ないな{{< /voice >}}

銘柄の数を増やしても、**全部同じ業種なら分散になっていない**わけです。

## 実際に18業種へ散らしました

候補をまとめた表には、最初から **セクターの列** を作っていました。

結果として、こうなりました。

| セクター | 銘柄数 |
|---|---|
| 化学 | 5 |
| サービス | 5 |
| 情報・通信 | 5 |
| 卸売 | 3 |
| 小売 | 3 |
| 不動産 | 2 |
| 食料品 | 2 |
| 倉庫・運輸関連 | 2 |
| 金属製品 | 2 |
| 保険・電気機器・精密機器・建設・機械・ゴム製品・その他製品・医薬品 | 各1 |
| J-REIT | 1 |

**18業種**に分かれました。

一番多い業種でも **5銘柄**。全体の2割に届いていません。

{{< voice c="chapio" side="left" >}}化学が5つあるの、意外じゃないですか？{{< /voice >}}

{{< voice c="maoneko" side="right" >}}そう？{{< /voice >}}

### 1銘柄あたりは2〜3%

金額の配分も決めていました。

| | 割合 | 金額 |
|---|---|---|
| ほとんどの銘柄 | **2〜3%** | 6,000〜9,000円 |
| J-REITのETFだけ | **11%** | 33,000円 |

**1銘柄が全体の3%を超えない**ようにしています。

こうしておくと、1社が無配になっても **配当全体では3%減るだけ** で済みます。

---

## 「散らす」と「増やす」は違う

**銘柄数を増やすこと自体が目的ではありません。**

| | 銘柄数 | 業種 | どうなるか |
|---|---|---|---|
| ❌ | 36銘柄 | **全部 化学** | 業種に逆風が吹けば全部こける |
| ✅ | 36銘柄 | **18業種** | 1業種が沈んでも残りが生きる |

同じ36銘柄でも、中身がまったく違います。

数を増やすのは**手段**で、目的は **一緒に倒れる組み合わせを減らすこと** でした。

## やってみて思ったこと

セクター分散は、**守りの考え方**でした。

利回りを上げるためのものではありません。  

**配当が急に減る日に備えるため**のものです。

| | |
|---|---|
| 利回りを上げたい | → 高い銘柄に寄せる |
| **配当を減らしたくない** | → **業種を散らす** |

私がやりたいのは後ろのほうでした。猫の医療費を配当でまかなうのが目的なので、

**毎年ちゃんと入ってくること**のほうが大事です。  

{{< voice c="chapio" side="left" >}}目的がはっきりしてると、選び方も決まりますね{{< /voice >}}

## まとめ

- **セクター＝業種**。分散とは業種を散らすこと
- **同じ業種は、同じ理由で一緒に減配する**
- 実際に **36銘柄を18業種** に散らした
- 一番多い業種でも **5銘柄**、1銘柄あたり **2〜3%**
- **数を増やすことと、散らすことは別**
- 買えない銘柄は **無理に埋めずに見送った**

利回りの高い順に買うのが一番効率がよさそうに見えて、**実は一番まとめて倒れやすい買い方**でした。
