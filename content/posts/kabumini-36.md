高配当株を始めようと思ったとき、最初につまずいたのがここ。

**株は100株からしか買えない。**

利回りの高い銘柄を調べて、いざ買おうとすると。

{{< voice c="maoneko" side="right" >}}1銘柄で40万円……？！{{< /voice >}}

1銘柄買うだけで、数十万円が飛んでいく計算になります。

これでは分散もなにもありません。

## 実は、1株から買えました

でも**今は1株から買えます。**

正確には **単元未満株** という仕組みで、  

100株に満たない数でも売買できるようになっています。

ネット証券では、割と当たり前に用意されているサービスです。

| | |
|---|---|
| 楽天証券 | かぶミニ |
| SBI証券 | S株 |
| マネックス証券 | ワン株 |

名前は違いますが、やっていることはほぼ同じようです。

{{< voice c="chapio" side="left" >}}100株じゃないと買えないのは、もう昔の話ですね{{< /voice >}}

私は楽天証券を使っているので、ここからは **かぶミニ** の話になります。

---

## 28万円で36銘柄買いました

2026年10月、**282,559円**で **36銘柄** を買ってみました。

| | 銘柄数 | 金額 |
|---|---|---|
| かぶピタッ | 27銘柄 | 225,000円 |
| かぶミニ | 9銘柄 | 57,559円 |
| **合計** | **36銘柄** | **282,559円** |

1銘柄あたりにすると、**大体6,000円〜9,000円**。

一番安かった銘柄は **4,000円** でした。

{{< voice c="maoneko" side="right" >}}4,000円で株主になれるんか{{< /voice >}}

100株で買おうとしていたら、1銘柄で終わっていた金額です。

## 「かぶピタッ」と「かぶミニ」は別もの

ここが最初に分かりにくかったところです。

楽天証券には、1株から買える方法が **2つ** あります。

| | 何を指定するか | 買える株数 |
|---|---|---|
| **かぶピタッ** | **金額**（6,000円ぶん、など） | 小数になる |
| **かぶミニ** | **株数**（5株、など） | 整数 |

言葉で書くとピンと来ないので、実際の注文を並べます。

### かぶピタッ（金額で指定）

```
6,000円ぶん買う → 2.9201817株
9,000円ぶん買う → 1.78890876株
```

**金額がきれいで、株数が小数**になります。

### かぶミニ（株数で指定）

```
5株買う → 6,045円
2株買う → 5,720円
```

**株数がきれいで、金額が端数**になります。

{{< voice c="chapio" side="left" >}}指定するものが逆なんですね{{< /voice >}}

### どっちを使うか

私は **かぶピタッを中心**に使いました。

理由は単純で、**予算を割り振りやすいから**です。

36銘柄に分散すると決めた時点で、1銘柄あたりの金額を先に決めたほうが早い。

> 1銘柄6,000円 × ◯銘柄、ちょっと多めに出すところは9,000円

という組み方ができます。

でも、**かぶピタッで扱えない銘柄**もありました。

その分は、かぶミニで株数を指定して買っています。  

27銘柄と9銘柄に分かれたのは、そういう事情です。

## やってみて分かったこと

### ① 注文してすぐには約定しない

これが一番感覚と違いました。

普通の株は、注文すればその場の値段で買え流ようです。

単元未満株は **1日のうち決まったタイミングでまとめて処理される** ので、  

注文したあと少し待つことになります。

{{< voice c="maoneko" side="right" >}}押した瞬間に買えると思ってたな〜{{< /voice >}}

私の場合は、**10月13日に注文して、約定したのは10月14日**。

それでも数時間〜ですが、「今の値段で買う」ができない、  

という点だけ頭に入れておくとやりやすいですね。

### ② 手数料ゼロ、とは少し違う

買うときの手数料は **0円** です。

が、**かぶミニ** のほうには、**スプレッド**という上乗せがありました。

```
株価が1,000円のとき
→ 実際に買う値段は1,002円くらいになる
```

明細に「手数料」とは出ないので気づきにくいのですが、  

**実質そこが費用**です。

一方の **かぶピタッ** は、そのスプレッドがありません。

{{< voice c="chapio" side="left" >}}表に出ないコスト、一番見落としやすいやつですね{{< /voice >}}

とはいえ、数千円の買い物に対して数円〜十数円の世界です。  

100株買うために何十万円も用意することに比べると、  

気にする順番としては後ろでいいかなという感じ。

### ③ 株主優待はつかない

配当は**株数に応じてちゃんともらえます**。1株なら1株分です。

ただ、**株主優待は、ほとんどの銘柄で100株から**。

優待目当てなら、単元未満株は向いていないです。

私は配当が目的なので、ここは気にしていません。

## 元手が少ないほど、分散の意味が出る

ここが今回一番書きたかったところです。

**同じ28万円でも、使い方で結果がまったく変わります。**

| | 買える数 | もし1社が減配したら |
|---|---|---|
| 100株で買う | **1銘柄**（運がよければ） | **配当がまるごと消える** |
| 1株から買う | **36銘柄** | **36分の1が減るだけ** |

高配当株で一番困るのは、**減配**です。

会社の業績が悪くなって、配当が減ったり無くなったりすること。

1銘柄に全部入れていると、それが起きた瞬間に終わります。

36銘柄に分けていれば、1社がこけても **残り35社から配当が来ます**。

{{< voice c="maoneko" side="right" >}}全部に乗らんかったら、全部では負けんな{{< /voice >}}

{{< voice c="chapio" side="left" >}}急に強気ですね{{< /voice >}}

## まとめ

- 高配当株は **1株から買えます**（単元未満株）
- 楽天証券なら **かぶピタッ（金額指定）** と **かぶミニ（株数指定）**
- 実際に **282,559円で36銘柄**、1銘柄あたり6,000〜9,000円
- 一番安い銘柄は **4,000円**
- 注文してから **約定までに時間がかかる**
- かぶミニには **スプレッド**という上乗せがある
- **株主優待はつかない**。配当はちゃんともらえる

「高配当株はお金が貯まってから」と思っていました。

実際には、**貯まるのを待っている間に配当をもらい損ねていた**だけでした。
